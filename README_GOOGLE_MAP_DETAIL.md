# Google Maps風 トイレ詳細パネル

トイレ詳細を固定カードから、Google Mapsのような3段階のドラッグ式パネルへ変更しています。

## 操作

- トイレを選択すると、最初はコンパクトなPEEK表示になります。
- 上端中央の灰色ハンドルを上へドラッグするとHALF、さらに上へドラッグするとEXPANDEDへ広がります。
- 下へドラッグすると縮小します。
- ハンドルをタップしても PEEK → HALF → EXPANDED → PEEK の順で切り替えられます。
- パネル内の詳細情報は従来どおりスクロールできます。
- 右上の×ボタンは固定です。
- PEEKまで縮小すると詳細スクロール位置は自動的に先頭へ戻ります。

既存の現在地、口コミ、清掃依頼・ポイント、トイレ削除機能は変更していません。
