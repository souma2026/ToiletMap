# トイレ削除機能

この版では、ログインしているユーザーなら、作成者に関係なくどのトイレでも削除できます。

## 動作

1. 地図で削除したいトイレのピンをタップ
2. 詳細画面の「このトイレを削除」を押す
3. 確認ダイアログで「削除」を押す
4. Supabaseからトイレが削除される

清掃依頼中で報酬ポイントが設定されている場合は、削除前に依頼者へポイントを返金します。関連する口コミも同じ処理内で削除します。

## Supabase設定

`supabase/delete_toilet_setup.sql` を Supabase の SQL Editor で実行してください。

以前の「自分が追加したトイレだけ削除可能」版をすでに実行済みでも、このSQLをもう一度実行すれば関数が更新されます。
